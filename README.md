# Workshop "Response Surface Analyse"

In diesem Repository finden Sie ab dem 21.09.2026 die Materialien zum Workshop "Response Surface Analyse", der im Rahmen der FDZ Herbstakademie 2026 stattfindet.

Im Ordner *01_Vorbereitung_QuadGleichungen* finden Sie zudem die Datei "OSF_Material_B...", die Sie zur Auffrischung Ihres (Schul-)Wissens über die Interpretation von quadratischen Gleichungen nutzen können. Es reicht, wenn Sie dazu das OSF-Material B anschauen; und nur bei Interesse den Verweisen auf die mathematischen Herleitungen im anderen Dokument folgen. Beide Dateien gehören zum Supplemental Material eines Einführungspapers zur RSA (https://doi.org/10.1177/1948550618757600).

Um die Materialien herunterzuladen, klicken Sie oben auf das grüne Feld "Code" --> "Download ZIP". 

Alternativ können Sie einzelne Dateien herunterladen durch Rechtsklick --> "Ziel speichern unter".
